# Fullstack Scaffold

A modern fullstack application scaffold built with:

## Tech Stack

**Backend:**
- [Bun](https://bun.sh/) - Fast JavaScript runtime
- [Elysia](https://elysiajs.com/) - TypeScript web framework
- TypeScript for type safety

**Frontend:**
- [Vue 3](https://vuejs.org/) with Composition API
- Modern reactive frontend framework

**Database:**
- PostgreSQL (primary)
- Compatible with MySQL/MariaDB with minor schema adjustments

## Features

- 🚀 Fast development with Bun runtime
- 🔒 Type-safe backend with Elysia and TypeScript
- ⚡ Reactive frontend with Vue 3 Composition API
- 🗄️ Flexible database support (PostgreSQL, MySQL, MariaDB)
- 📦 Modern tooling and best practices
